# Pigeon Pitch, One Line

A city pigeon pitches investors its crumb-delivery startup — raising a seed round, literally, having already eaten half the seed.

`main.py` writes the one-line pitch (143 characters) to `/output/entry.txt`, with a self-check that it is a single line of 1–200 characters.
